# Changes — 2026-05-14

Two commits today on branch `integration/master-test`, plus UI/icon polish done in the same session.

---

## 1. ClassChung — Data Layer

### `GetNhanDangThuoc` signature overhaul
**Old:** `List<Thuoc> GetNhanDangThuoc(..., int? idHinhdang, ...)`
**New:** `List<NhanDangThuoc> GetNhanDangThuoc(..., List<int> idHinhdangs, ...)`

- Return type changed from `List<Thuoc>` to `List<NhanDangThuoc>`. The caller is now responsible for joining to `Thuoc`; the method itself only filters and returns identification records.
- Shape filter changed from a single nullable int to a list, enabling multi-shape OR queries in a single DB call (previously required one call per shape).
- `WHERE ... IN (...)` applied when `idHinhdangs` is non-null and non-empty.

### `null` imprint filter fix
`CoKhacDau == null` (value "Không rõ") previously still applied a boolean filter. Fixed: the `WHERE CoKhacDau = @hasImprint` clause is now skipped entirely when `hasImprint` is null.

### New: `GetDSNhanDangByThuoc(int idThuoc)`
Returns all `NhanDangThuoc` rows for a given drug ID as `List<NhanDangThuoc>`. Used by the Detail page to enumerate all physical variants.

### New: `DeleteAllThuoc_MauSacByIDThuoc(int idThuoc)`
Batch-deletes all entries in `r_Thuoc_MauSac` for a drug. Used by the WinForms admin before re-inserting color mappings.

## 2. PillIdentifierMVC — Search Flow

### Search action rewrite (`HomeController.Search`)

**Before:** For each selected shape, called `GetNhanDangThuoc` once (one DB call per shape), got back `List<Thuoc>`, unioned + deduplicated.

**After:** Single call to `GetNhanDangThuoc` with the full `List<int>` of shape IDs. Returns `List<NhanDangThuoc>`. Controller then:
1. Groups by `IDThuoc`, takes the first NhanDang per drug (for the result card).
2. Loads `GetDSThuoc()` filtered to matched drug IDs.
3. Joins everything in-memory to build `PillResultCard` list.

Net effect: fixed DB call count regardless of how many shapes are selected.

### Image loading — result cards
After building cards, a secondary loop calls `GetDSHinhAnhbyThuoc` per card to find the first image (ordered by `MoTa` as integer). URL is rewritten via `ToDriveDirectUrl` → `/Home/ImageProxy?fileId=...`.

### `ToDriveDirectUrl` + `ImageProxy` action
Google Drive share URLs (`?id=...`) are rewritten to the MVC proxy route. `ImageProxy` downloads the image server-side, sets a 7-day public cache header, and returns the bytes. This avoids CORS/hotlinking issues with direct Drive links.

## 3. PillIdentifierMVC — Detail Page

### Multi-variant physical properties (`PillDetailModel` refactor)

**Before:** `PillDetailModel` held a single `NhanDangThuoc NhanDang` plus flat resolved strings (`TenHinhDang`, etc.). Detail page showed properties from that one record.

**After:**
```csharp
public class NhanDangDetail
{
    public NhanDangThuoc NhanDang { get; set; }
    public string TenHinhDang { get; set; }
    public string TenDangThuoc { get; set; }
    public string TenLoaiRanh  { get; set; }
    public string TenLoaiVi    { get; set; }
}

public class PillDetailModel
{
    public Thuoc Thuoc { get; set; }
    public List<NhanDangDetail> NhanDangs { get; set; }   // ← was single NhanDang
    public List<MauSac> Mausac { get; set; }
    public string TenHoatChat { get; set; }
    public List<HinhAnhThuocChiTiet> HinhAnhList { get; set; }
}
```

`Detail.cshtml` now iterates `nhanDangs`, extracts distinct values per field, and renders them as comma-joined strings. A drug with two packaging variants (e.g. blister and bottle) shows both shapes, both blister types, etc.

### Image carousel
Replaced the single static `<img>` with a full carousel:
- Main viewport: slides with prev/next buttons and a `1/N` counter.
- Thumbnail strip below: horizontally scrollable, scroll arrows appear only when overflow exists.
- JS is inline and scoped to an IIFE — no global namespace pollution.
- Images loaded from `hinhAnhList` ordered by `MoTa` (integer sort, fallback to end).
- Images filtered to the first NhanDang's ID to avoid duplicates (images are stored per NhanDang but are drug-level in practice).

CSS additions in `Site.css`: `.detail-carousel`, `.carousel-main`, `.carousel-slide`, `.carousel-btn`, `.carousel-counter`, `.carousel-thumbs-wrapper`, `.carousel-thumb`, `.thumb-scroll-btn`.

## 7. IconHelper — New Shapes and Colors

### Shape ID 22 — Hình nang (pharmaceutical capsule)
```csharp
case 22:
    inner = "<rect x='1' y='6' width='20' height='10' rx='5' .../>" +
            "<line x1='11' y1='6' x2='11' y2='16' .../>";
    break;
```
Rounded rectangle (same outline as ID 8 "Hình thuôn dài") **plus a center vertical dividing line**, making it visually identifiable as a two-part capsule shell.

### Color ID 44 — Đen (Black): `#212121`
### Color ID 45 — Xám (Gray): `#6D6D6D`

Color selection rationale:
- `#212121` is clearly black with no confusion against any existing swatch.
- `#6D6D6D` is noticeably darker (~50 RGB units) than the existing "Khác" `#9E9E9E`, avoiding visual confusion while remaining unmistakably gray.
- Black swatch uses border `#555` (visible against dark background); light-colored swatches (IDs 8, 40, 42, 43) use border `#ccc`; all others use `rgba(0,0,0,0.1)`.
